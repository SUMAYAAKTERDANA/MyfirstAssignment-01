# 🚀 DevConf 2026

A modern and responsive **developer conference website** built for DevConf 2026. The website provides information about speakers, conference pricing, a 24-hour hackathon challenge, and registration.

## 📌 Project Overview

**DevConf 2026** is a developer conference landing page designed for engineers, founders, and developers.

The website includes different sections to showcase the conference details, speakers, pricing plans, hackathon information, and social media links.

## 🛠️ Technology Stack

* HTML5
* CSS3
* Font Awesome
* Responsive Web Design

## ✨ Features

* 🧭 Navigation bar
* 🎤 Meet the Speakers section
* 💰 Conference pricing plans
* 📋 Standard, Pro, and Team packages
* 🏆 24-Hour Hackathon Challenge section
* 📱 Responsive design
* 🔗 Social media icons
* 📢 Registration buttons
* 🦶 Footer section
